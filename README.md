# Mini Search Engine

A beginner-friendly DSA project using **Trie, Hash Map, Graph, Heap, TF-IDF-style ranking**, and document search.

## Requirements
- Python 3.10+
- No external packages required

## Run
```bash
cd mini-search-engine
python src/main.py
```

## DSA used
- **Trie:** autocomplete suggestions
- **Hash Map:** inverted index and term frequencies
- **Graph:** document links
- **Heap:** top-k ranked results
- **Ranking:** TF-IDF-style relevance score + title/link boosts
